管理决策转盘，帮用户创建"转一转随机决定"的转盘。支持以下操作：

【列表】
- list: 列出所有转盘及其选项，无需参数。返回的 wheel id 供 update_options / delete 使用；每个转盘自带 deeplink，可直接打开该转盘的转动页。

【创建转盘】
- create: 创建一个新转盘，需传 title（转盘标题，如"午餐吃什么"）和 options（选项名称数组，至少 2 个，如 ["火锅","烧烤","沙拉"]）。选项配色自动生成，无需指定。结果中的 deeplink 直达新转盘的转动页，可引导用户点击后立即转一转。

【更新选项】
- update_options: 整体替换指定转盘的选项列表并重新配色，需传 wheel_id 和 options（至少 2 个）。先用 list 拿到 wheel_id。结果中的 deeplink 同样直达该转盘的转动页。

【删除】
- delete: 删除指定转盘，需传 wheel_id。
